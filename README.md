# gohan-tabeta（ごはん食べた）

日毎のカレンダーで朝・昼・晩（＋間食）の食事、カロリー、写真を記録するシンプルな食事管理ツール。スマホ最適化済みのPWA。

## 機能
- 月カレンダー：日ごとの合計kcal、記録済みの食事をドット表示、目標超過は赤字。月の記録日数・1日平均・合計
- 日ビュー：朝食/昼食/夕食/間食をタブ＋左右スワイプで切替。品目＋kcal、写真（複数可・自動圧縮）、メモ。目標に対する進捗バー
- 全画面1枚に収まるレイアウト（ページ全体はスクロールしない。品目が多い時のみリスト内スクロール）
- ダッシュボード：週／月／期間指定（7・30・90・365日プリセット、任意の日付範囲）で集計
  - 1日平均・目標内の日数・合計、日別カロリーの棒グラフ（目標ライン付き、62日超は週平均）、食事別の平均
  - 棒をタップでその日の値を表示し、日ビューへ移動できる
- 画面下部のナビでカレンダー／ダッシュボード／設定を切替
- よく食べるもののプリセット（タップでkcal加算）
- 目標カロリー設定、JSONエクスポート/インポート（写真込み）
- ホーム画面に追加でアプリのように全画面表示、オフライン動作

## 使い方
ビルド不要の静的サイト。任意の静的サーバで配信するだけ。

```sh
npx http-server -p 8080 .
```

公開する場合は GitHub Pages（Settings → Pages → Deploy from a branch → `main` / root）で動く。

## データ保存について
- データは**端末のブラウザ内（IndexedDB）にのみ**保存される。サーバ送信なし
- 端末間同期はない。機種変更・ブラウザのデータ削除で消えるため、設定画面から定期的にエクスポートすること
- iOS Safari はホーム画面に追加しないと長期間未使用時にデータが消える可能性がある

## 構成
- `index.html` / `css/style.css`
- `js/app.js` 画面（ハッシュルーティング）、`js/dashboard.js` ダッシュボード、`js/db.js` IndexedDB、`js/util.js` 共通処理、`js/foods.js` プリセット
- `sw.js` オフラインキャッシュ、`manifest.webmanifest` PWA設定
